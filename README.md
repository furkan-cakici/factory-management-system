# Endüstriyel Fabrika Yönetim Sistemi

Mobil ve web üzerinden fabrika içi günlük operasyonları (yemek menüsü yönetimi, acil duyurular ve personel bildirimleri) koordine eden uçtan uca mimariye sahip bir yönetim platformu.

---

## Teknoloji Mimarisi

- **Mobil Uygulama (Android):** Kotlin, Jetpack Compose, Modern UI
- **Backend API:** FastAPI (Python), RESTful mimari, Render Cloud Deploy
- **Yönetici Paneli (Web):** Streamlit, Python, Pandas
- **Veritabanı:** PostgreSQL (İlişkisel Veritabanı)

---

## Temel Yetenekler

- **FastAPI Arka Plan Servisleri:** Mobil istemciler ve yönetici paneli arasında düşük gecikmeli veri akışı.
- **Yönetici Paneli (Streamlit):** İK veya idari amirlerin tek tıkla günün yemek menüsünü girmesi ve acil duyurular yayınlaması.
- **Modern Mobil Arayüz:** Jetpack Compose ile duyarlı kartlar, acil durum etiketleri ve canlı bildirim takibi.
